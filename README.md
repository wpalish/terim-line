# TerimLine 0.1

Оригинальная текстовая репетиция плоского keypad-меню RU/KK: опубликованная версия, ввод владельца, единый срок, порядок событий и точный исход. Это отдельный ограниченный процесс по общему направлению reference9 Retell AI, а не копия его платформы.

## Запуск

Нужен Node.js >=24.15 <25. Сторонних зависимостей нет. Задайте собственный пароль14–200 символов через WORK_ADMIN_PASSWORD, затем:

```sh
PORT=8849 PUBLIC_ORIGIN=http://127.0.0.1:8849 npm start
```

Первый администратор по умолчанию admin; WORK_ADMIN_USER меняет имя. HOST по умолчанию127.0.0.1. База .data/workspace.sqlite; DATABASE_PATH меняет путь. Пароль не вписывать в репозиторий. Если администратор уже есть, env не меняет его пароль. Для внешнего размещения нужны отдельные HTTPS, резервирование и эксплуатационная проверка; это не поставлено.

```sh
npm test
```

26 предметных тестов. [Проверки](docs/verification.json), [браузер](docs/browser-proof.json), [исходный референс](docs/reference-audit.md), [пределы](PRODUCT.md).

## Один процесс

1. Администратор создаёт меню: оба текста RU/KK, ожидание5–300секунд и предел1–5 неверных цифр.
2. Добавляет1–10 разных цифр0–9 с двумя подписями и модельным исходом. Черновик может быть неполным; публикация проверяет полный снимок.
3. Явно публикует конкретную версию. Публикация неизменна, поздние правки черновика не переписывают её; одинаковая версия повторно не публикуется даже после архива.
4. Сотрудник начинает собственную RU/KK-сессию. Сервер фиксирует владельца, начало и срок. Только этот аккаунт добавляет события.
5. Неизвестная цифра расходует попытку и не продлевает срок; допустимая цифра до срока завершает модель. Отмена до срока даёт cancelled. На границе и после срока тайм-аут важнее цифры/отмены.
6. Читает полный неизменный журнал и опубликованное меню. Течение времени само ничего не записывает: требуется явное действие владельца.

Новая команда требует актуальные общую revision и expectedSeq; использованный requestKey получает отказ, а не повторный успех. В UI при конфликте цифра остаётся введённой, автоматического объединения/повтора нет. Предпросмотр не резервирует и не является обязательным HTTP-подтверждением.

Архив меню/публикации закрывает новые сессии, прежние активные продолжаются по снимку. Активную сессию нельзя скрыть архивом, передать или открыть заново после конца. Общая область видна всем сотрудникам; администратор не может действовать за владельца.

## Копия и ограничения

Администратор скачивает JSON и восстанавливает только в пустую область. Проверяются снимки, сроки, последовательность и результаты; JSON и SHA256 не подписаны и не доказывают автора. Аккаунты, auth-сессии и аудит не входят. Лимит HTTP JSON2МБ; полную SQLite базу резервировать согласованно отдельно. UI сброса пароля/отзыва сессий нет.

Это не звонок, DTMF carrier, голос, ASR/TTS, LLM, перевод, реальная передача, сообщение или интеграция. HUMAN — код исхода модели. Нет оценки реального разговора, качества сотрудника, согласия или услуги. Результаты и источники синтетические. Полного внешнего аудита безопасности/нагрузки/всего мобильного кабинета нет.

Общая оригинальная Node/SQLite-инфраструктура переиспользована из собственных продуктов; правила keypad-сессии, интерфейс и проверки написаны для TerimLine. Код MIT; чужие закрытые исходники/бренды не копировались. Подтверждённых покупателей и выручки нет.
